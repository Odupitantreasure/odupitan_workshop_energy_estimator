## What It Does

The Workshop Energy Cost Estimator is a Python program designed to calculate the energy consumption and electricity costs of machines used in a workshop.

It calculates the daily and monthly energy consumption of machines in kilowatt-hours (kWh) and estimates their electricity costs.

## How to Run It

1. Install Python 3.
2. Download the Python file.
3. Open your Python environment.
4. Run the following command:

python workshop_energy_estimator.py

## Features

- Calculates daily energy consumption.
- Calculates monthly energy consumption.
- Estimates daily and monthly electricity costs.
- Displays total energy consumption.
- Handles invalid numerical inputs.
